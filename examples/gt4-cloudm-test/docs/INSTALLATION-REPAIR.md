## 固件静态证据

分析输入：`../firmware/5.0.0.88/extracted/images/phoinix_mcu_m55_application.image.bin`，SHA-256 `8b31ddeec6de01e92b428e5c07f672a0a432b1fb949ac1bc5afe462d88ce8660`。

- `0x2c3b22c8`：安装流程。`0x2c3b246a` 发出 70；之前已通过签名/配置检查、解包、JS 转字节码。
- `0x2c3b24d4` 调用 `0x2c3b279a`：目录提交、安装记录备份、新安装的数据目录创建。
- `0x2c3b24f2` 调用 `0x2c3b262c`：从代码目录拼接 `/assets/<module>/resources/rawfile`，移至数据目录 `/rawfile`。
- `0x2c3b26b0` 调用 `0x2c3b1356` 目录重命名；失败分支返回内部 `0x12`。
- `0x2c3b2508` 发出 80：上述步骤之后。
- `0x2c3b1356` 最终调用 `0x2c17d22c`，后者跳入 ROM 地址 `0x64df3`。

实测对照支持 rawfile 安装期迁移是触发条件。设备的 103 回包没有携带详细内部错误，不能将静态看到的 `0x12` 写成已经从设备读出的错误码。ROM 内部失败原因及 BLE 映射仍在进一步分析。

## 独立固件分析补充与暂停状态

用户要求暂时不连接手表/手机；没有执行本次新准备的日志读取工具。

子代理独立核对的 BLE 错误映射：`0x2c13a944` 回调进入 `0x2c13a82a`；内部错误 0 映射成功 102，0xc8 映射进度，0x18 映射 113，其他非零错误在 `0x2c13a8de` 统一映射 103。回包是 SID42/CID2，仅含状态和包名，没有原始内部错误。因此安装脚本未遗漏这个回调的详细错误字段。

70–80 区间可返回内部 0x12（目录重命名）、0x14（数据目录创建）、0x15（安装记录保存）、0x0a（参数/内存）。目前不能将 0x12 写成已从设备取得的值。

原始错误在 `0x2c13a8ca` 写日志，格式 ID 为 `0x3e187688`。已有本地日志与编码器交叉核对的记录格式：`ED, severity(U8), module(U8), argc(U8), timestamp(U32LE), formatID(U32LE), argc 个 U32LE 参数`。目标日志特征为 `ed 04 05 01` + 时间 + `88 76 18 3e` + 内部错误值。旧本地 gpu_debug 片段无命中，不能用此推断当前设备无相关日志。

下一步可在用户恢复设备连接后，限定读取 GPU debug 日志窗口，在内存中过滤上述目标记录；不读取健康/GPS日志，不保留无关日志。目前仅准备了本地适配器，尚未进行这次设备日志读取。
